# Friend Host (NeoForge 1.21.1, NeoForge 21.1.250)

Open your single-player world to friends with an invite code.

## Build on GitHub (no install needed)
1. Create a new GitHub repository.
2. Upload ALL the files and folders from this project (including the `.github` folder).
3. Open the **Actions** tab. The build starts by itself (about 3-5 minutes).
4. When it is green, open the run and download **friendhost-mod** at the bottom. Unzip it to get the `.jar`.
5. Put the `.jar` in your `mods` folder. Friends need the same `.jar` to use the Join screen.

## Use it
- Host: load your world, press Esc, click **Host for friends**, click **Start hosting**, then **Copy invite code**.
- Friend: on the title screen click **Join with code** and paste the code.
- Friends outside your home network need port forwarding (default 25565) or a tunnel address typed in the address box.

If the build fails, copy the red error text from the Actions log and send it back.
